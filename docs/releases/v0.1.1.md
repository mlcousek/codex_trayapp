# Codex Usage Tray 0.1.1

First public release of the unofficial Windows tray utility for Codex account
usage and optional local token analytics.

- Multi-size program icon, quota ring, flyout and dark/light Settings.
- Refresh after Windows resumes, while preserving request floors and retry backoff.
- Tray redraws after shell/DPI changes and guards against updates during shutdown.
- Distinct connection/sign-in/CLI compatibility messages, retry countdowns and recovery guidance.
- Quota charts break across missing readings and resets; downsampling preserves breaks.
- Executable and home-directory pickers, path validation, and Windows high-contrast colors.
- Fixed Settings startup caused by missing XAML styles.
- Account-isolated history/cache, local token analytics, threshold alerts and optional weekly release checks.

## Install or update

Download the ZIP for your Windows architecture (`win-x64` or `win-arm64`).
Extract it to a per-user folder. Quit an existing copy before replacing the
program files, then launch `CodexTrayApp.exe`. Both packages are self-contained
and include pricing, the MIT license, README and SHA256 checksums.

Settings and history stay in their separate per-user app-data folders. Keep
those folders when updating. Codex CLI and ChatGPT sign-in supply subscription
usage; API-key sign-in supports local analytics without subscription percentages.

The binaries are unsigned. Windows x64 Release build and 505 tests pass;
synthetic light/dark flyout and Settings captures were reviewed. Arm64 runtime,
physical sleep/wake, real Explorer restart, high-contrast switching and
constrained 200-percent desktop interactions still require device verification.
